TP PHP — Suivi des notes
1. Installez PHP.
2. Ouvrez un terminal dans le dossier tp_php.
3. Lancez : php -S localhost:8000
4. Ouvrez http://localhost:8000/exo1_bases.php
5. Pour tester le stockage, ouvrez saisie.html et ajoutez plusieurs apprenants.
Remplacez [Votre nom] et "Mon établissement" par vos informations.
Le dossier data doit être accessible en écriture par PHP.
